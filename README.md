# Aion

**Clean. Privacy-first. Fast.**

Experience the web with ease and confidence. Aion brings a thoughtful balance of speed, privacy, and everyday convenience to your browsing.

## What we're building

- **Minimal UI:** compact layouts, consistent design, less clutter.
- **Privacy by default:** no telemetry, no sponsored content, clear permissions.
- **Performance:** responsive navigation, efficient resource use.
- **Quality of life:** useful shortcuts, better tab management, thoughtful defaults.
- **Developer-friendly:** powerful developer tools and an open, maintainable codebase.
